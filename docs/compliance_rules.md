# 持仓分析合规规则与待核验项

2026-10-08。本文是产品控制清单，不是完整法律意见。附件是参考摘要，不作为当前法规有效性的证明。原型不因增加免责声明即取得经营证券投资咨询业务的资格。

| ID | 产品规则 | 实现/验证 | 法律依据核验方向 |
|---|---|---|---|
| H01 | 不生成个股买卖、加减仓、目标价格或时点 | Prompt约束+输出拦截+越界案例；仍需人工语义评测 | 证券投资顾问业务资质与业务边界 |
| H02 | 不承诺收益、不预测保本 | 输出拦截、静态情景明确非预测 | 投资者权益、宣传与风险揭示 |
| H03 | 指标附来源、日期、口径 | 从输入和计算器生成，不交给模型杜撰 | 信息真实准确完整相关要求 |
| H04 | 区分AI生成与程序计算 | 页面和导出双重标识 | AI生成合成内容标识规则的适用性 |
| H05 | 最小必要与告知 | 仅概括指标发模型，显式确认，无账号/姓名 | 个人信息保护法、第三方委托处理 |
| H06 | 密钥不入日志或报告 | 会话内存、HTTPS、禁重定向、受控错误 | 信息安全和访问控制 |
| H07 | 数据不足不推断适当性 | 无正式风险测评时不称已匹配；不因低风险等级屏蔽用户对已有持仓的风险了解 | 适当性规则按业务场景确定 |
| H08 | 失败/越界可降级至事实 | 模型失败保留指标，交易问题拒答 | 人工服务、应急处置机制 |
| H09 | 不以陈旧数据冒充实时 | 7日产品阈值提醒，CSV源标识 | 数据质量与信息披露 |
| H10 | 生产记录可追溯且限权 | V1仅用户导出；生产需明确留存期限、权限及删除机制 | 证券基金经营机构信息技术管理及隐私要求 |

待逐项核验：适用牌照、合作券商审批人、数据来源许可、云模型委托协议、出境安排、备案/安全评估适用条件、标识细则、日志保存依据。不能仅依赖“敏感词过滤”证明内容合规。

参考入口（法规有效版本需另行核实）：中国证监会 https://www.csrc.gov.cn/ 、中国网信网 https://www.cac.gov.cn/ 、国家法律法规数据库 https://flk.npc.gov.cn/ 。
