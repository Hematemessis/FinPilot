# FinPilot V4：个股筛选与研究建议能力

## 产品升级结论

V4 将从“资产配置 Agent”升级为“资产配置＋个股研究 Agent”。

新版可以分析具体上市公司，也可以根据公开新闻、估值和财报筛选候选股票；但不能只凭一个评分或一条新闻直接输出买入结论。

## 三层能力

### 第一层：股票筛选

Agent 在预先定义的股票池中应用流动性、数据完整性、盈利质量、增长、估值和风险规则，形成研究候选名单。

这一层的输出是：

- 优先研究候选；
- 继续观察；
- 数据不足；
- 暂不考虑。

筛选结果不是最终买入建议。

### 第二层：公司分析

进入候选名单的公司需要形成一张证据卡：

- 公司靠什么业务赚钱；
- 收入和利润是否持续增长；
- 经营现金流能否支持利润；
- 负债是否可能形成压力；
- 当前价格相对自身历史和同行是否昂贵；
- 最近财报、管理层指引和重要新闻改变了什么；
- 市场可能已经提前计入了什么预期；
- 最先可能证明判断错误的风险是什么。

### 第三层：有条件的研究建议

只有财报、估值、价格和新闻证据都达到最低完整度时，Agent 才能输出具体股票建议。建议不是简单的“买入/卖出”，而是：

- 为什么进入推荐；
- 更适合哪类用户和持有期限；
- 当前估值是否允许介入；
- 哪些条件满足后才值得行动；
- 哪些信号出现后应放弃判断；
- 在总资产配置中最多承担什么角色和比例。

## 初版筛选框架

| 维度 | 初版权重 | 面向小白的解释 |
|---|---:|---|
| 财务质量 | 30% | 赚到的钱是否真实、稳定，负债是否可控 |
| 业务增长 | 20% | 收入和利润是否持续改善 |
| 估值 | 20% | 当前价格是否已经透支太多好消息 |
| 新闻与催化剂 | 15% | 最近发生的事情是否改变未来经营判断 |
| 市场风险 | 15% | 波动、历史下跌和交易流动性是否适合小白 |

权重是首版产品假设，需要通过历史测试和用户研究验证，不能直接表述为最优模型。

这五项分数只用于排列“先研究谁”，不能直接转换成买入建议。正式判断还必须依次通过硬门槛、数据可信度、反方论证、估值口径和用户风险适配检查；严重风险不能被其他维度的高分平均掉。完整方法见 [V4_STOCK_RESEARCH_METHOD.md](V4_STOCK_RESEARCH_METHOD.md)。

## 数据与证据要求

### 市场数据

- 当前价格、历史价格、成交量、波动和最大历史下跌；
- 同时保留 TTM PE 和 NTM/FY1 动态 PE，明确预测期、预测来源、分析师数量和更新时间；
- 检查最近 30/90 天盈利预测修正和预测分歧，不能只按动态 PE 从低到高排名；
- 亏损或利润接近零时不使用 PE，改用行业适配的估值指标；
- 数据时间戳和币种；
- 不用延迟行情冒充实时行情。

### 财报与公司披露

- 收入、利润、现金流、负债、股份数量和关键业务指标；
- 优先采用交易所、监管机构、公司公告和投资者关系材料；
- 保留报告期、单位和原始来源。

### 新闻与事件

- 新闻发布时间、信息来源和涉及的公司；
- 区分公司公告、权威媒体报道和市场传闻；
- 把新闻映射到收入、利润、现金流、估值或风险，不能只做情绪正负面分类；
- 过期新闻不能继续作为“近期催化剂”。

## 面向投资小白的表达

| 专业术语 | 默认表达 |
|---|---|
| 市盈率 PE | 当前股价相当于过去一年每股利润的多少倍 |
| 动态市盈率 | 按市场预计的未来一年利润，现在股价相当于多少年利润 |
| 盈利预测修正 | 分析师最近是在上调还是下调公司未来利润预期 |
| 预测分歧 | 不同分析师对未来利润的看法有多不一致 |
| 估值分位数 | 现在比它自己过去大多数时候贵还是便宜 |
| 自由现金流 | 公司扣除维持经营所需投入后真正剩下的钱 |
| 资产负债率 | 公司资产中有多少依靠借款和债务支持 |
| 盈利质量 | 账面利润是否真的转化成现金 |
| 催化剂 | 未来可能让市场重新认识这家公司的事件 |
| 证伪条件 | 出现什么情况说明原来的判断错了 |

## 新用户旅程

1. 用户先完成资产配置，明确总资金中有多少可以承担股票风险。
2. Agent 询问行业偏好、持有期限和是否接受高波动，不让用户选择复杂财务指标。
3. Agent 在受控股票池中筛选，并最多展示三个候选，避免信息过载。
4. 每个候选用“赚钱能力、价格贵不贵、最近发生什么、最大风险”四张卡说明。
5. 用户选择一家公司后进入深度分析，查看财报趋势、估值比较、新闻证据和判断失效条件。
6. Agent 把个股建议重新放回整体资产配置，检查集中度和最大可承受损失。
7. 用户得到的是研究建议和风险上限，不是自动下单。

## V4 仍然不能做

- 不根据一条新闻或单一财务指标直接荐股；
- 不推荐数据不足、流动性差或无法核验信息来源的股票；
- 不把筛选排名宣传成预期收益排名；
- 不生成没有来源支撑的盈利预测和目标价；
- 不把未说明预测期和来源的“动态市盈率”当作可靠证据；
- 不进行日内交易、自动下单或保证收益；
- 不在没有重新拉取数据时把旧结论冒充当前结论。

## 第一阶段市场范围

求职演示版调整为优先支持 A 股和港股。行情演示使用东方财富公开前复权日线；A 股公告与财报以巨潮资讯、上交所和深交所为一手来源；港股公告与财报以披露易和公司投资者关系网站为一手来源。

公开历史行情只用于回测和流程演示。授权财经新闻、NTM/FY1 一致预期和动态估值尚未接入，不能抓取网页值冒充稳定预测数据。数据源分级、失败回退和生产缺口见 [CHINA_MARKET_DATA_SOURCES.md](CHINA_MARKET_DATA_SOURCES.md)。

个股调查的完整节点、动态估值口径、新闻证据规则、研究状态和验证方法见 [V4_STOCK_RESEARCH_METHOD.md](V4_STOCK_RESEARCH_METHOD.md)。
