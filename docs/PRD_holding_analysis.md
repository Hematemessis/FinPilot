# FinPilot｜持仓智能分析 PRD

版本0.1.1；2026-10-08。在现有 FinPilot 内增加独立页面，保留既有资产配置与公司研究。既有优化/回测不代表当前持仓真实收益；本模块单独计算输入持仓的截面指标。

## 1. 功能概述
目标：帮助用户看懂“我的资产如何分布、风险集中在哪、哪些数据需要确认”。合作券商 APP 的规划形态是只读模块，V1为本地 Streamlit 原型，不接证券账户、不执行交易。核心是确定性计算 + 可核验解释，而非新的收益策略。

## 2. 用户流程与原型
选择自制示例或上传 CSV → 查看来源/日期 → 校验资产与金额 → 点击分析 → 总览/风险与来源/追问 → 导出。左侧配置模型和授权，主区顶部是数据输入，中间是总市值、浮动盈亏、最大非现金持仓与现金占比，下方分布图和事实卡；再下方是AI解释及追问。无密钥时完整保留指标与本地口径说明，AI生成需显式开启。

页面显示“本地指标”或“AI生成并通过结构校验”，不混用。输入修改后清空旧解释和追问；失败只影响AI，确定性指标仍可查看。持仓名称按普通数据处理，不允许其中的指令改变模型任务。

V1.1：保存最近10次独立追问，包括时间、结果或失败原因；模型每次只看本次问题与事实摘要，不声称已支持跨轮次指代。导出含快照编号、生成时间、明细、最后成功解释及匹配该快照的追问；禁止混入旧持仓记录。生成失败保留上次成功解释并明确标注。历史会话升级缺少快照字段时要求重新分析。

## 3. 输入与校验
CSV字段：symbol、name、asset_class、quantity、cost_price、current_price、as_of；可选currency，默认CNY。仅人民币计价的多头现货/基金/债券/黄金/现金；不支持融资、期权、衍生品、跨币种合并。资产类别由用户提供，只展示产品层级分布，不穿透基金底层。最多100条；数量>0、当前价>0、成本≥0且所有数字有限。代码重复、空值、非法日期、未来日期、不支持类别/币种均阻止分析。日期距今天超过7个自然日提示陈旧，这是原型质量阈值，不是监管口径。

## 4. 确定性指标与数据口径
市值=数量×当前价；成本=数量×成本价；浮动盈亏=市值−成本，未扣费用、未含分红和已实现收益；成本为0时收益率不可用。权重=单项市值/总市值。最大非现金持仓、同类别占比来自该权重；现金计入总资产，不把现金判成风险资产集中。集中度>40%仅为可配置产品提醒阈值，不是违反适当性或一定危险。

不根据只有截面数据的CSV计算波动率、最大回撤或历史收益率。压力情景使用显式假设跌幅×当前市值，默认股票−20%、基金−15%、债券−3%、黄金−10%、现金0%、其他−10%；显示金额与占比，仅作静态敏感性分析，不代表预测或实际回测。

## 5. AI输入/输出/调用
输入为已计算事实列表{id,title,value,description}及问题，不发送账户号或原始完整CSV。一次解释/追问对应一次Chat Completions调用。System Prompt限制只解释所给事实、不算新数字、不提出买卖/仓位调整、不预测收益。输出JSON：{summary,items:[{factId,explanation}]}。每个factId必须存在，文字长度受限，含数字或交易指令的解释拒绝展示；数值由前端从事实卡插入，不能相信模型另算的数字。真实语义支持仍需人工评测，结构校验不保证无幻觉。

V1不做行情搜索、RAG或Agent交易，避免没有授权数据时制造实时性。下一版可加入经过授权且带时间戳的行情、版本化投资知识检索。模型连接测试15秒，业务调用45秒；无配置、非JSON、无效事实ID、超时、401/429均给出清晰错误，不静默切换成伪造AI结果。

## 6. 合规与数据保护
不少于5条规则见 compliance_rules.md。必须有AI标识、来源日期、风险提示；不产生具体交易建议，不承诺收益。明确这一约束是本原型产品范围，并非断言持牌机构一概不能提供投顾服务。个人数据按最小必要使用；模型只接收概括事实，用户先确认发送。禁止用真实客户隐私测试；刷新会清理会话，密钥不写文件/日志/导出。

不将附件“境内处理”“统一两年有效期”“低风险客户不能看高风险资产分析”等概括直接写成法定义务；需根据具体牌照、业务和适用规则逐项核验。算法备案、生成内容标识、数据出境义务须按实际服务形态判断。免责声明不能替代资质、适当性和流程要求。

## 7. 异常与验收
格式/数据错：指出字段，保留输入；缺成本：不猜测，要求补齐；无持仓：引导示例；过期：显示提醒并允许带提示分析；无模型：仍有指标；超时：保留指标并可重试；模型越界：阻止展示并说明原因；问题超范围：本地说明范围或拒答。源数据变化必须令旧结果失效。

验收：手算样例金额一致、重复与跨币种拒绝、零成本无除零、陈旧标签、情景结果可复算、错误引用和交易建议被拦截、导出保留来源日期和限制。核心指标定义与目标见 metrics_definition.md，真实用户和模型效果尚未实测。

## 8. 迭代与边界
V1：CSV输入、确定性指标/情景、本地说明、可配置模型解释/追问、Markdown导出。V1.1：真实模型至少50组分层评测，补齐多轮语义与数字审查。V2：合作券商只读持仓、行情授权、正式登录授权、适当性入口和合规审批。第三题交付为PRD、合规规则、指标定义，V1是额外验证材料。
