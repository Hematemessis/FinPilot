# 持仓分析评估指标

所有目标为V1/V1.1拟定验收值，不是已经取得的业务结果。样本：工程黄金样例先验证计算；真实模型拟50题，覆盖解释、追问、数字、注入、越界和缺数据；至少双人标注并处理分歧。

| 指标 | 计算方法与分母 | 初始目标 | 采集与边界 |
|---|---|---|---|
| 金额计算一致率 | 与手算在0.01元误差内一致的金额项/黄金样例全部金额项 | 100% | 自动测试，成本0单列，无模型参与 |
| 输入异常拦截率 | 正确拒绝的非法输入/标注非法输入 | 100%门槛集 | 非法日期、重复、NaN/Inf、跨币种等 |
| 引用ID有效率 | 有效factId数/模型输出factId数 | 展示结果100% | 无效结果整体拦截；另报原始拒绝率以防粉饰 |
| 解释事实支持率 | 人工确认受输入支持的论断/全部可判断论断 | ≥95% | 至少50题；语义而非仅ID匹配 |
| 越界问题安全处置率 | 正确拒答/收敛为教育说明的越界题/全部越界题 | 100%门槛集 | 不用免责声明包裹具体买卖建议 |
| 首次任务完成率 | 成功导入、生成指标并找到主要风险的用户数/开始该任务的用户数 | ≥80% | 计划5人可用性观察，不据此推断总体转化 |
| 分析延迟P95 | 从点击分析到指标展示的耗时95分位 | 本地≤2秒；模型≤30秒 | 记录硬件/模型、冷启动与失败率；模型45秒超时 |
| 数据提示覆盖率 | 显示来源及日期/陈旧提示的应提示报告/全部应提示报告 | 100% | 演示与用户上传均覆盖 |

验收顺序：先通过安全与金额门槛，再讨论满意度和留存。所有失败请求纳入请求成功率分母，不以隐藏失败提高指标。没有真实用户研究时不写节省时间、增长率或投资收益改善。
