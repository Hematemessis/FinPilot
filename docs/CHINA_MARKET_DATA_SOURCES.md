# FinPilot A股/港股数据源设计

## 结论

产品的数据底座已从美股演示组合切换为面向中国投资者的 A 股和港股体系。资产配置层接入公开历史日线并保留离线回退；公司研究层已经接入贵州茅台 3 份上交所报告和腾讯 2 份公司年报/中报。新闻和一致预期仍按一手证据优先原则登记来源，没有完成授权接入的字段不会展示为真实值。

## 行情适配器口径

- 接口：东方财富 `push2his` 公开历史接口。
- 频率：日线。
- 复权：前复权。
- 时间范围：默认从 2018 年到运行当天。
- 校验：证券代码一致、价格为正、日期去重、至少 120 个共同交易日、四类资产按共同日期对齐。
- 元数据：记录来源、币种、复权方式、数据截止日期以及“非生产授权行情”标记。
- 回退：联网或数据校验失败时切换到固定随机种子的合成数据，并在界面显式提醒。

## 研究证据优先级

1. 法定披露、交易所和监管机构原文；
2. 公司投资者关系材料，并保留“公司说法”标签；
3. 获得授权的行情、新闻和一致预期服务；
4. 可追溯的二手报道，只作为线索，不代替原始证据；
5. 模型推断，只能生成待验证假设，不能生成事实、目标价或一致预期。

严重数据缺口不能被其他高分抵消。个股筛选结果只能标为“继续研究候选”“等待验证”或“数据不足”；只有来源、口径、时效和关键风险都通过检查后，才能进入更深的投资判断，仍不等于个性化买入建议。

## 当前证据包

- `Source_Index.csv`：来源 ID、报告期、URL、页码和新鲜度。
- `Normalized_Financials_Long.csv`：营收、利润、经营现金流、每股收益等关键指标的长表归一化数据。
- `QA_Flags.csv`：动态估值缺口、审计状态、现金流口径和数据范围限制。
- `Validation_Checks.csv`：实际执行的来源覆盖、单位、报告期和关键数字核验。
- `filing_manifest.json`：本地 PDF 页数、文件大小和 SHA256；PDF 本身不提交到 Git 仓库。

## 生产化仍需补齐

- 购买或接入有 SLA 的 A 股/港股授权行情；
- 对接公告检索、正文下载、版本留存和字段归一化；
- 获得财经新闻版权与结构化接口授权；
- 获得分析师一致预期、预测修正、覆盖人数和分歧度数据；
- 处理 A 股与港股不同的交易日历、停牌、公司行动、币种和会计口径；
- 建立数据新鲜度、缺失率、异常值、源间冲突和失败回退监控；
- 在给出购买份数前接入实时盘口、最小交易单位、费用和用户持仓。
