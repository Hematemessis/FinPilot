# FinPilot V4：个股调查方法 v0.2

## 文档定位

这份方法用于回答两个问题：Agent 为什么把一家公司列为研究候选，以及在什么证据满足后，才可以形成有条件的研究意见。

它是 V4 的研究设计，不代表当前应用已经接入实时财报、分析师预测或新闻数据。任何真实个股结论都必须标注数据截止时间、来源和缺失项。

## 一句话方法

先用硬门槛排除“不适合研究”的公司，再分别调查生意、财报、估值与市场预期、新闻事件和下行风险；最后给出“继续研究、等待价格、等待验证、暂不考虑”之一，而不是用一个总分直接输出买入结论。

```text
受控股票池
  → 身份、流动性和数据完整度检查
  → 生意与竞争力调查
  → 财报质量与增长调查
  → 动态估值与市场预期调查
  → 新闻、催化剂和风险调查
  → 反方论证与判断失效条件
  → 用户适配和组合风险检查
  → 研究状态＋证据卡＋下一步
```

## 五条研究原则

1. **筛选不等于推荐**：分数只决定先研究谁，不能直接决定买什么。
2. **好公司不等于好股票**：公司质量和当前价格必须分开判断。
3. **事实、预测和判断分开**：公司披露、市场一致预期、模型计算和 Agent 推断必须分别标记。
4. **先找反对理由**：每个正面观点都要配套一个最先可能推翻它的指标或事件。
5. **所有结论都有保质期**：价格、预测和新闻必须带时间戳；重大财报或事件出现后重新调查。

## 第一阶段：定义调查范围

在读取股票数据前，先明确：

- 市场、交易所、股票类别和基础货币；
- 用户持有期限、可承受波动和可投资于个股的金额；
- 行业偏好和明确排除项；
- 最低市值、成交活跃度和数据完整度；
- 本次任务是“找候选”“分析指定公司”还是“复查已有观点”。

如果用户没有指定，求职演示版默认采用流动性较好的 A 股和港股大中盘公司，以及 1—3 年基本面视角。A 股与港股分别使用自己的证券代码、交易日历、币种和法定披露来源，不能混用财报口径。

## 第二阶段：硬门槛检查

以下检查优先于评分。命中严重问题时，Agent 输出“数据不足”或“暂不考虑”，不能靠其他高分抵消。

### 身份与交易检查

- 公司、股票代码、交易所和股份类别是否对应；
- 是否存在 ADR 换算、双重上市、换股或退市风险；
- 币种、财年截止日和报告口径是否一致；
- 成交活跃度是否满足产品设定的最低要求。

### 数据完整度检查

- 最新年报、季报和关键业务数据是否可获得；
- 当前价格、总股本和净负债是否有明确截止时间；
- 动态估值使用的盈利预测是否说明来源、预测期和更新时间；
- 重大公司行动是否已反映在财务和股份数据中；
- 不同来源是否存在尚未解释的重大冲突。

### 一票否决或强制降级

- 核心数据无法核验或已经明显过期；
- 审计意见、财务重述或治理问题使利润可信度不足；
- 流动性过低，不适合面向普通用户展示；
- 结论主要依赖未经证实的传闻；
- 重大并购、拆分或业务变化导致历史数据不可比；
- 盈利或现金流口径存在无法解释的异常。

## 第三阶段：调查公司靠什么赚钱

Agent 需要先理解生意，再读取估值倍数。

### 必答问题

1. 谁在付钱，购买什么产品或服务？
2. 收入按业务、地区和客户如何构成？
3. 增长来自销量、价格、产品组合、并购还是汇率？
4. 公司依靠什么维持竞争优势，这个优势能否观察和验证？
5. 最大客户、供应商、监管或单一产品依赖是什么？
6. 管理层如何分配赚到的钱：再投资、收购、回购、分红还是偿债？

### 输出

- 一句话商业模式；
- 主要收入和利润驱动；
- 两到三个可持续性证据；
- 一个最先可能破坏商业逻辑的因素；
- 尚未查清的问题。

## 第四阶段：调查财报质量和增长质量

默认观察最近 3—5 个完整财年和至少 8 个季度；历史较短或业务发生重大变化时单独说明。

### 财务质量

- 收入、毛利率、营业利润率和净利润的趋势；
- 经营现金流和自由现金流能否支持账面利润；
- 应收账款和存货是否长期快于收入增长；
- 净负债、利息负担和短期偿债压力；
- 股权激励、增发和回购后的实际股份稀释；
- ROIC、ROE 或行业适配的资本回报指标；
- 一次性损益、重组、资产出售和会计口径调整。

### 增长质量

- 增长是内生还是依赖并购；
- 增量收入能否带来利润和现金流；
- 增长是否集中在单一客户、地区或短期价格因素；
- 未来增长需要投入多少资本；
- 管理层历史指引是否经常兑现。

### 财务异常提醒

Agent 不直接判定“造假”，只标记需要人工复核的异常，例如：

- 利润增长但经营现金流持续恶化；
- 应收账款或存货明显快于收入；
- 经常性使用“一次性调整”美化利润；
- 大额关联交易或商誉增长；
- 回购金额很大，但摊薄股数没有下降；
- 审计机构、会计政策或财年口径突然变化。

## 第五阶段：调查动态估值和市场预期

估值不是寻找“最低倍数”，而是判断当前价格已经反映了多少增长，以及预测是否可信。

### 市盈率的三种口径

| 口径 | 计算含义 | 用途 | 主要风险 |
|---|---|---|---|
| TTM PE | 当前股价 ÷ 过去 12 个月摊薄每股收益 | 看已经实现的盈利对应什么价格 | 历史利润可能不能代表未来 |
| NTM PE | 当前股价 ÷ 未来 12 个月一致预期摊薄每股收益 | 看未来一年预期利润对应什么价格 | 依赖分析师预测，可能快速下修 |
| FY1/FY2 PE | 当前股价 ÷ 下一/下两个财年预测每股收益 | 观察估值随盈利增长的变化路径 | 财年口径和远期预测误差更大 |

产品中的“动态市盈率”默认指 NTM 或 FY1 一致预期市盈率。不能把“最近一个季度利润乘以四”的年化口径和一致预期口径混在一起，尤其不能只显示一个没有定义的“动态 PE”。

### 动态市盈率必须附带的证据

- 预测 EPS 的提供方和数据截止时间；
- 使用 NTM、FY1 还是 FY2；
- GAAP/IFRS、调整后还是 Agent 自行归一化口径；
- 基本还是摊薄股数；
- 覆盖分析师数量；
- 最近 30/90 天盈利预测上调或下调幅度；
- 预测分歧程度；
- 最近一次财报和指引是否已进入一致预期。

### 估值比较顺序

1. 与公司自己的 3—5 年可比历史区间比较；
2. 与业务模式、增长、利润率和资本结构相近的同行比较；
3. 与自身增长、资本回报和现金流质量比较；
4. 使用适合该行业的第二种估值方法交叉验证；
5. 检查当前价格是否已经包含乐观情景。

### PE 不适用时

- 亏损或利润接近零：不显示有误导性的 PE；
- 银行和保险：优先考虑 P/B、ROE、资产质量等；
- REIT：优先考虑 P/FFO 或 P/AFFO；
- 高增长未盈利公司：可用 EV/Sales，但必须同时看毛利率、现金消耗和盈利路径；
- 重资产和周期行业：结合 EV/EBITDA、正常化利润、资产负债表和周期位置；
- 现金流成熟公司：补充自由现金流收益率和资本回报。

### 防止动态 PE 陷阱

- 周期高点利润异常高，使 PE 看起来很低；
- 市场预测尚未反映价格、需求或成本恶化；
- 未来 EPS 增长主要来自回购或一次性税率变化；
- 调整后利润长期排除真实、反复发生的成本；
- 分析师覆盖少、预测分歧大，却展示过度精确的倍数。

## 第六阶段：调查新闻和事件

新闻模块不做简单的正面/负面情绪打分，而是回答“这件事改变了哪个经营假设”。

### 来源优先级

1. 监管文件、交易所公告和正式财报；
2. 公司投资者关系材料和管理层公开讲话；
3. 可信媒体、监管部门和行业机构；
4. 社交媒体和市场传闻只能作为待核实提醒，不能支撑推荐。

### 每条事件的调查字段

- 发生时间、公开时间和数据抓取时间；
- 原始来源与二手来源；
- 新信息是什么，哪些只是重复报道；
- 影响收入、利润率、现金流、资本开支还是风险溢价；
- 影响方向、预计持续时间和可能量级；
- 是否已经反映在公司指引、市场预测和股价中；
- 下一条可以验证影响的财务或业务指标。

同一新闻不能永久充当催化剂。超过有效期或已被财报验证后，应转为历史证据或关闭事件。

## 第七阶段：形成投资论点，而不是拼接摘要

每家公司都要把“公司事实”和“股票判断”分开。

### 最小论点结构

- **已知事实**：公司和行业已经发生了什么；
- **市场预期**：当前估值和一致预测大致要求什么；
- **可能的预期差**：市场可能高估或低估了哪个驱动；
- **为什么是现在**：什么数据窗口或事件会让市场重新判断；
- **第一反对理由**：最强的反方解释是什么；
- **验证条件**：哪些指标改善后，观点才更可信；
- **失效条件**：出现什么情况应停止沿用原判断。

如果找不到清晰的预期差，Agent 应输出“公司值得了解，但暂时没有发现价格层面的机会”，不能用“好公司”替代股票结论。

## 第八阶段：情景和下行检查

对进入深度研究的公司建立乐观、基准和悲观三种情景。每种情景都要使用可观察的经营驱动，而不是只修改目标价。

| 情景 | 必须说明 |
|---|---|
| 乐观 | 哪些收入、利润率或现金流假设超预期，以及证据窗口 |
| 基准 | 当前最合理的经营和估值路径 |
| 悲观 | 需求、竞争、成本、融资或治理如何导致损失 |

下行分析优先回答“钱会怎么亏”，包括盈利下修、估值收缩、负债压力、股份稀释和流动性冲击。数据不足时只输出情景框架，不生成目标价。

## 第九阶段：证据可信度和研究状态

### 证据标签

每个关键结论都标记为：

- 事实；
- 公司说法；
- 市场一致预期；
- 模型计算；
- Agent 推断；
- 数据缺口。

### 数据可信度

可信度不参与平均加权，而是独立显示：

- **A**：主要数据来自最新一手材料，口径一致且无重大缺口；
- **B**：核心数据可用，但预测、同行或事件证据仍有缺口；
- **C**：关键数据陈旧、冲突或依赖低可信来源，只能作为调查线索。

### 面向用户的研究状态

- **值得继续研究**：基本面和证据达到深度分析门槛；
- **等待更好价格**：公司判断尚可，但当前价格已经包含较多乐观预期；
- **等待业绩验证**：核心假设需要下一次财报或业务指标确认；
- **数据不足**：无法形成可靠判断；
- **暂不考虑**：触发硬门槛、风险不匹配或核心论点已失效。

这些状态不是收益承诺，也不是自动买卖指令。

## 第十阶段：回到用户和组合

个股研究不能绕开用户最初的资产配置约束。进入“有条件研究意见”前，Agent 必须检查：

- 用户是否有足够的应急资金；
- 个股资金是否来自原本允许承担波动的部分；
- 单一公司、单一行业和同一风险因子的集中度；
- 悲观情景损失是否超过用户可承受范围；
- 是否需要用宽基资产代替用户并不理解的个股风险。

求职演示版只给出研究角色和风险上限，不连接证券账户，也不自动下单。

## 第十一阶段：持续复查机制

Agent 的价值不止是第一次回答，还要记住原判断并在新证据出现时复查。

### 固定复查

- 每次季报和年报后；
- 公司更新正式指引后；
- 估值和一致预期超过设定保质期后。

### 事件触发复查

- 盈利预测出现显著上调或下调；
- 核心管理层、审计机构或资本结构变化；
- 重大并购、监管、诉讼、产品或客户事件；
- 股价变化使估值进入新的历史区间；
- 原先定义的验证条件或失效条件被触发。

复查输出必须说明：什么发生了变化、影响了原论点的哪一部分、研究状态为何升级或降级、下一次观察什么。

## Agent 节点和输入输出

| 节点 | 主要输入 | 核心规则 | 输出 |
|---|---|---|---|
| 任务理解 | 用户目标、期限、风险承受力 | 不让用户选择专业算法 | 调查范围和限制 |
| 股票池 | 市场、行业、市值、流动性 | 只在受控且可核验的范围工作 | 合格股票池与排除原因 |
| 证据采集 | 财报、行情、预测、新闻 | 保留来源、口径和时间戳 | 原始证据表 |
| 财务归一化 | 历史报表和业务指标 | 处理一次性项目、币种、财年和摊薄股数 | 可比较财务序列 |
| 估值分析 | 价格、盈利、现金流、同行 | TTM 与 NTM/FY1 并列，行业适配 | 估值状态与可信度 |
| 事件分析 | 公告、财报、新闻 | 映射到经营驱动，不只判情绪 | 事件影响卡 |
| 论点与反方 | 全部证据和市场预期 | 必须包含第一反对理由和失效条件 | 研究论点与状态 |
| 组合护栏 | 资产配置、集中度、可承受损失 | 个股意见不能突破用户风险预算 | 风险上限和替代方案 |
| 解释与记忆 | 用户语言偏好、历史观点 | 默认白话，保留专业依据 | 用户卡片与复查任务 |

语言模型负责理解问题、组织证据和生成解释；数值计算、口径转换、规则判断和状态更新由确定性模块执行。语言模型不能自行编造缺失的财务数据或目标价。

## 筛选分数如何使用

V4 现有的财务质量、增长、估值、新闻与风险五个维度，只用于形成研究优先级。正式流程采用：

```text
硬门槛 → 分维度调查 → 数据可信度 → 反方检查 → 研究状态
```

不能采用：

```text
五项加权总分最高 → 直接推荐
```

原因是严重负债、财务可信度不足或估值口径失效，不能被其他维度的高分平均掉。面向用户可以展示五张结论卡；专业明细中再展示指标和研究过程。

## 如何验证这套方法

### 研究回放测试

- 只使用当时已经公开的数据，避免偷看未来；
- 使用当时的股票池，避免只保留后来存活的公司；
- 保存当时的价格、预测和新闻版本；
- 分别比较 3、6、12 个月后的相对收益和最大下跌；
- 记录候选、等待和拒绝三类的命中率与误报原因；
- 与简单基准比较，例如等权、低估值或高质量筛选；
- 单独统计换手、交易成本和覆盖率。

历史回放只能验证方法在特定样本中的表现，不能证明未来有效。

### 产品验证

- 用户能否理解“为什么出现这个候选”；
- 用户能否说出最大风险和判断失效条件；
- 用户是否把“研究候选”误解成“保证上涨”；
- 用户能否在三分钟内完成候选比较；
- 用户是否愿意查看证据来源或继续追问。

### 求职展示边界

可以展示：方法设计、节点输入输出、离线样例、证据链、回放测试和用户理解测试。

不能宣称：当前已经覆盖全市场、已经拥有实时一致预期、研究分数能够预测收益，或未经验证的权重优于其他方法。

## MVP 落地顺序

1. 分别建立 20—50 只 A 股和港股大中盘公司的受控研究池；
2. 用巨潮资讯、沪深交易所、披露易和公司 IR 固化可复现的财报与公告样例；
3. 实现财务归一化、TTM PE 和基础同行比较；
4. 接入有明确来源的 NTM/FY1 一致预期和预测修正；
5. 实现事件到收入、利润率、现金流和风险的映射；
6. 生成候选卡、公司深度卡和失效条件；
7. 加入历史回放与数据保质期检查；
8. 最后再把个股风险接回资产配置和用户旅程。

如果无法获得稳定且有授权的预测数据，MVP 应暂时只展示 TTM 估值和“动态估值数据不足”，不能用模型自行猜测一致预期。
