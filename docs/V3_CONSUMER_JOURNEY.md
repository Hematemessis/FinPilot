# FinPilot V3：面向投资小白的用户旅程

## 产品定位

FinPilot V3 是“资产配置陪伴 Agent”；V4 在它之后增加受控的 A 股/港股调查流程。配置层不把个股直接塞进核心仓位，研究层也不把筛选候选自动变成买入结论。

它解决的问题是：用户有一笔钱，但不知道该留多少现金、承担多少市场风险，以及如何在增长、防守和分散风险之间分配。

一句话价值主张：**先弄清你能承受什么，再给你一份看得懂的分散配置方案。**

## V1 能力边界

### 能做

- 通过投资目标、期限、流动性和亏损承受力形成风险画像。
- 在现金、宽基股票、债券、黄金等资产类别之间给出比例建议。
- 把比例换算成用户实际投入金额。
- 在结果主页面展示当前回测对应的人民币产品：510300、159920、511260、518880 和现金用途。
- 解释比例如何由风险问卷、现金底线、集中度约束和训练区间数据共同生成。
- 用历史测试说明组合可能经历的波动和阶段性亏损。
- 解释为什么这样配置，并在超过用户承受范围时给出预警。
- 比较更稳健的替代方案。

### 不能做

- 当前运行版不输出真实个股买入名单，不预测哪只股票短期上涨。
- 不进行实时买卖，不连接用户证券账户。
- 可以展示基于财报、估值、公告和新闻的调查流程，但在授权数据未接入前不形成真实公司结论。
- 不把演示 ETF 映射包装成适合所有用户的真实购买名单，也不在缺少实时价格和汇率时计算购买份数。
- 不保证收益，也不把历史回测当作未来结果。
- 不处理税务、法律、跨境交易和个体化合规建议。

## 为什么配置层不直接做个股推荐

投资小白首先需要解决的是风险预算和资产分散，而不是扩大可选股票数量。个股推荐需要实时行情、基本面、估值、事件风险、适当性和更严格的合规控制；如果当前系统没有这些证据，直接给出股票名单会放大误导风险。

当前版本把回测使用的 510300、159920、511260、518880 显示为“产品示例”。四只产品都在沪深交易所以人民币交易，其中 159920 提供港股市场敞口，仍需提醒汇率、跨境额度、溢折价和跟踪误差。后续的“资产类别内产品筛选”还要从合规白名单中比较费率、规模、流动性和跟踪质量；这与预测个股涨跌是两项不同能力。

## 新用户旅程

### 0. 首次进入

Agent 先说明能做和不能做什么，并用“开始制定方案”作为唯一主操作。

### 1. 说清目标

用户回答：这笔钱用来做什么、准备投入多少、多久不用、近期是否可能支取。

Agent 输出一句复述，确认自己理解的目标和时间范围。

### 2. 了解承受力

用户回答：最多能接受多大阶段性亏损、收入是否稳定、市场下跌时通常如何反应。

Agent 将答案转成现金下限、集中度上限和回撤阈值，但不向普通用户暴露计算术语。

### 3. 给出方案

结果页优先回答四个问题：

1. 我的钱分别放到哪里？
2. 每一部分分别解决什么问题？
3. 历史上可能经历多大阶段性亏损？
4. 为什么这个方案适合我的回答？

页面以人民币金额和生活化资产名称表达；比例使用 100% 横向资金条，A股、港股、国债、黄金和现金五段资金与具体 ETF 示例一一对应，复杂公式和专业指标放入“查看计算依据”。

### 4. 调整与陪伴

用户可以要求“再稳一点”或重新测评。未来版本再增加定期复查、偏离提醒和再平衡建议。

## 文案分层

| 专业表达 | 默认用户表达 | 展示位置 |
|---|---|---|
| 权重 | 这笔钱的多少比例 | 结果主页面 |
| 最大回撤 | 历史上从高点最多跌了多少 | 结果主页面 |
| 年化收益 | 历史测试中平均每年的增长速度 | 计算依据 |
| Sharpe | 承担波动是否值得 | 计算依据 |
| 最小方差 | 更稳一点的方案 | 调整按钮 |
| 最大夏普 | 收益风险比优先方案 | 仅专业比较 |
| 样本外 | 没参与方案计算的历史区间 | 计算依据 |

## Agent 感知设计

Agent 感来自“主动提问、复述理解、调用工具、检查风险、解释选择和提供下一步”，不是来自页面上出现 Agent 字样或聊天气泡。V3 的每个界面节点都对应一个可验证的决策动作。
